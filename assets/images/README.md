# Foundation photography

Homepage photos are managed through [`data/homepage-media.json`](../../data/homepage-media.json). Add approved, optimized WebP photos to this folder, set the matching `src` and descriptive `alt` values in the manifest, and set `consentConfirmed` to `true` only after the required permissions are documented.

| Manifest key | Suggested filename | Suggested subject |
| --- | --- | --- |
| `hero` | `hero.webp` | Teenagers reading and playing sport together |
| `reading` | `reading-programme.webp` | Teenagers reading or studying in a community space |
| `sport` | `sport-programme.webp` | Youth cricket or sports training in action |
| `founder` | `founder-and-community.webp` | Founder with community members |
| `story-reading` | `reading-story.webp` | A consent-approved literacy achievement |
| `story-sport` | `sport-story.webp` | A consent-approved team or sports achievement |
| `story-leadership` | `leadership-story.webp` | A young person leading or mentoring |
| `event-reading` | `reading-event.webp` | A reading campaign or book event |
| `event-sport` | `sports-event.webp` | A clinic, match, or training session |
| `event-community` | `community-event.webp` | Volunteers and partners at an activation |
| `volunteer` | `volunteer-activity.webp` | A coach, reading mentor, or volunteer supporting youth |
| `gallery-reading` | `gallery-reading.webp` | Reading-circle highlight |
| `gallery-sport` | `gallery-sport.webp` | Sports-session highlight |
| `gallery-community` | `gallery-community.webp` | Community engagement highlight |

Use original Foundation photography, not stock or AI-generated participant imagery. Obtain guardian consent before publishing identifiable images of anyone under 18; use descriptive, privacy-conscious alt text and avoid names, school identifiers, precise locations, or sensitive context. Keep original high-resolution images in the Foundation's secure archive rather than this public folder.
